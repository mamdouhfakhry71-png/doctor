نظام العيادة الذكية (ويندوز 7 / 10 / 11)
=======================================
التشغيل السريع: افتح index.html في أي متصفح.
بناء ملف exe: ثبّت Node.js ثم شغّل build.bat (أو GitHub Actions زي نظام المتجر). التجربة: npm install ثم npm start

الدخول: admin / admin123 (الدكتور - كل الصلاحيات)  و  work / work123 (العامل - المرضى فقط)
غيّر كلمات السر من شاشة المستخدمين.

الشاشات: الرئيسية، المواعيد، المرضى (ملف كامل لكل مريض)، روشتة إلكترونية، الحسابات (للدكتور)، المستخدمون، الإعدادات.
- واتساب: الأزرار بتفتح محادثة المريض والرسالة جاهزة (تذكير موعد / روشتة). الإرسال التلقائي بالكامل من غير ضغطة محتاج WhatsApp Business API.
- البيانات بتتحفظ على الجهاز. خد نسخة احتياطية من الإعدادات بشكل دوري.
- لا تغيّر نسخة electron (22.3.27) عشان ويندوز 7.
